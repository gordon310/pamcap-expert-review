## 手机填写

1. 在手机浏览器打开问卷，按章节填写；可切换章节，随时保存草稿。
2. 各公式附变量含义、单位、适用条件及待确认项；请在对应评审意见中确认或修改。
3. 完成后选择“检查并分享答卷”。浏览器支持时可分享答卷文件；不支持时可下载文件或复制答卷内容发回。
4. 微信内功能受限时，请选择在系统浏览器中打开。请在聊天中确认答卷已经发送。

## 回收

发起人在“回收汇总”导入文件或粘贴专家回传的完整答卷内容。可导出逐题汇总及备份。

答案仅保存在填写者浏览器或导出文件中，不会自动上传到 GitHub。请勿将已填写答卷提交到此公开仓库。

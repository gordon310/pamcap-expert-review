# 酒店资产估值专家评审问卷

螃蟹树聚酒店资产估值专业评审，共 26 项，问卷版本 V1.0。

## 填写方式

1. 使用 Chrome、Edge 或 Safari 打开网页。
2. 逐项选择意见，填写专业细则与依据。
3. 点击“校验并导出正式答卷”，将下载的 HTML 文件发回问卷发起人。

## 回收方式

发起人在“回收汇总”中导入专家返回的 HTML 或 JSON 文件，可导出逐题 CSV、回收包和意见汇总。

答案仅保存在填写者浏览器或导出文件中，不会自动上传到 GitHub。请勿将填写后的答卷提交到此公开仓库。

本仓库仅包含公开分发的空白评审问卷，不包含产品程序、客户数据或实际专家答卷。
